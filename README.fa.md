# Payload Mail

[English](README.md) · مجوز MIT · حق نشر ۲۰۲۶ امیرحسین سلیقه‌دار

صندوق ایمیل خصوصی کارکنان در پنل موجود Payload. دریافت و تحویل ایمیل همچنان با Postal انجام می‌شود. افزونه صندوق صفحه‌بندی‌شده، جستجو، پیش‌نویس پایدار، پاسخ، پاسخ به همه، بازارسال، یادداشت داخلی، پیوست خصوصی و تاریخچهٔ تحویل را فراهم می‌کند. سرویس IMAP، پنل جداگانه، پاسخ خودکار، رهگیری یا نیاز اجباری به Redis ندارد.

**وضعیت: نسخهٔ آزمایشی آلفا؛ تأیید محیط عملیاتی هنوز انجام نشده است.** نام `payload-plugin-mail` موقت است و انتشار عمومی npm انجام نشده. برای نصب، بستهٔ ساخته‌شده از همین مخزن را استفاده کنید. [گزارش شواهد](docs/evidence.md) مرجع نتیجهٔ واقعی آزمون‌ها و محدودیت‌هاست.

هدف اولیه Node 22.23.4، Payload و آداپتور SQLite نسخهٔ 3.90.2، Next 16.3.3 و React 19.2.6 است. در حال حاضر فقط SQLite در محدودهٔ پشتیبانی است.

```sh
pnpm install --frozen-lockfile
pnpm build
npm pack
```

فایل `tgz` را در برنامهٔ میزبان نصب کنید. نمونهٔ پیکربندی کامل در [راهنمای انگلیسی](README.md) است. دسترسی پیش‌فرض بسته است؛ مجوز کارکنان و صندوق را مطابق کاربران میزبان مشخص کنید. فایل `payload-plugin-mail/styles.css` را در layout پنل وارد کنید و `pnpm payload generate:importmap` را اجرا کنید. مسیر پیش‌فرض پنل `/admin/mail` و API برابر `/api/mail` است.

پردازش `processMail(payload, options, 10)` باید با زمان‌بند موجود هر ۱۰ تا ۳۰ ثانیه اجرا شود. پیش از تغییر مسیر ایمیل واقعی، کلید عمومی امضای Postal، ذخیره‌سازی پایدار، کنترل دسترسی، نسخهٔ پشتیبان و محدودیت مشترک درخواست را بررسی کنید.

زبان رابط با تنظیمات Payload هماهنگ است. فارسی راست‌به‌چپ است و آدرس‌ها و شناسه‌ها جهت مستقل چپ‌به‌راست دارند. متن ایمیل با جهت خودکار نمایش داده می‌شود. زبان رابط دادهٔ نامه را تغییر نمی‌دهد. تقویم، ارقام و منطقهٔ زمانی صریحاً قابل تنظیم‌اند؛ پیش‌فرض میلادی، ارقام لاتین و UTC است.

HTML تنها با درخواست کاربر، پاک‌سازی‌شده و در قاب محدود نمایش داده می‌شود. تصاویر خارجی پیش‌فرض مسدود هستند. پیوست‌ها در پایگاه دادهٔ خصوصی نگهداری می‌شوند و دانلود نیازمند مجوز صندوق است. بدون اتصال اسکنر، ادعای بررسی بدافزار وجود ندارد.

پذیرش سرویس، تحویل به سرور گیرنده و قرارگیری در Inbox سه مرحلهٔ متفاوت‌اند. قطع اتصال پس از ارسال ممکن است نتیجه را نامشخص کند؛ ارسال نامشخص خودکار تکرار نمی‌شود. ابتدا وضعیت را در Postal بررسی کنید. تضمین تحویل دقیقاً یک‌بارهٔ SMTP ارائه نمی‌شود.

```sh
pnpm typecheck
pnpm lint
pnpm test
pnpm test:consumer
pnpm exec playwright install chromium
pnpm test:e2e
```

نمونه و آزمون‌ها فقط از حساب‌ها و پیام‌های ساختگی استفاده می‌کنند. هیچ اطلاعات ورود نمونه یا endpoint شبیه‌ساز را به محیط عملیاتی منتقل نکنید. [تصویر واقعی رابط فارسی](docs/screenshots/inbox-fa.png) از آزمون مرورگر با پیام‌های ساختگی ثبت شده است.
