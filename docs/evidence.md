## Material limits

- Only Node 22.23.4 / Payload-UI-SQLite 3.90.2 / Next 16.3.3 / React 19.2.6 is tested. No PostgreSQL/MongoDB claim.
- Production must use a shared admission limiter and proxy byte/concurrency limits. Generic hosts supply a hook; Moftkhar's implementation uses existing Redis with real concurrency tests.
- Small private DB attachments have base64 overhead. No scanner is claimed without a hook; no large-file streaming or automatic orphan-byte reclamation is implemented.
- Retention defaults to dry-run, rechecks SQLite eligibility transactionally, skips pending/unknown work and threads over 100 messages, and retains shared attachment bytes. No silent data deletion on uninstall/rollback.
- No exactly-once SMTP or Inbox-placement guarantee. Unknown acceptance requires operator reconciliation.
- Production alpha.4 image identity, staff UI/language/access, controlled support/Gmail round trip and notification delivery remain unverified. Alpha.3 incoming route and durable processing are proven; SQL diagnostics are not staff UI/access evidence.
